# Archive

Retired code, kept for reference. Nothing here is part of the app or the release zips.

## crowd-control-standard/

The original **Crowd Control** bridge: TikTok LIVE gifts → game effects, with no
control panel or overlays. It shipped inside `Rando-Hub-v*.zip` (the "Crowd Control"
folder) from v1.0.0 to v1.3.7, so any of those releases on the
[Releases page](https://github.com/hugecrankhank/Rando-hub/releases) still has a
working copy.

From v1.4.0 crowd control is **Crowd Control+** only (`crowd-plus/`, the second
download): the same bridge plus a control panel and stream overlays. Its
`mapping.json` reads the old file as-is: copy yours into the Crowd Control+ folder
to keep your gift setup.
