CROWD CONTROL+  -  WHAT'S NEW
=============================

Crowd Control+ is Rando Hub's crowd control: the gift bridge with a
control panel and stream overlays. Every gift effect, big-donation seed
roll and the subathon clock work exactly as before.

NEW IN 1.9.18
------------
- Scrolling gift list: 1 to 4 rows (Gifts & effects tab → Scrolling
  gift list), so more gifts show at once. Make the browser source
  72 px taller per row.
- Gifts & effects tab: put the gifts in any order (drag the handle, or
  the arrows), then Save. The scrolling gift list follows that order.

NEW IN 1.9.16
------------
- Room lights: lights_on (a dark room lit up as if every torch were
  lit, 60s) and lights_out (any room nearly black, 30s; outdoors the
  screen dims). Pick them for gifts on the Gifts & effects tab.

NEW IN 1.9.15
------------
- reveal_item (HydeOut's idea): a gift shows where one item the run
  still needs is, read from the seed's spoiler. A banner on the game,
  a mark on Mudora 2.0's map, and a clip marker. Seeds made in the hub
  only; race seeds keep their spoiler hidden.

NEW IN 1.9.14
------------
- Seed history: every seed played, with when, its code, which game,
  who rolled it and how, and a link to play it again. In the control
  panel (Live games tab, saved in seeds.json, Download as CSV) and in
  the hub (Settings menu > Seed history).

NEW IN 1.9.13
------------
- Halloween effects: spooky_night (everything purple and orange),
  ghost_link, pumpkin_link, haunted_lights (flickering, lightning),
  spooky_monster and haunting (ghosts, bats, mummies, skeletons),
  trick_or_treat (50/50 treat or trick) and spooky_sprite. Pick them
  for gifts on the Gifts & effects tab. Details in INSTRUCTIONS.txt.

NEW IN 1.9.11
------------
- Digging Game guessing (Live games tab): like the GT big key game.
  Chat guesses which dig gives the Digging Game's prize (!dig 1-30);
  the game says which dig it was. New "Digging Game" overlay.
- The seed reroll banner on the game sits at the very top now (over
  the hearts and rupees), so it doesn't cover the play area.

NEW IN 1.9.6
------------
- Ticker (scrolling gift list): when a reroll switches between Zelda 3
  and Zelda 1, the list changes to the new game's effects within a few
  seconds. Gifts whose effect that game doesn't have are left out.
- Rerolls with "Rerolls can land on either game" on: "New seed (same
  settings)" never changes games. "Random preset seed" and "CHAOS seed"
  can, and roll the same kind in the other game.

NEW IN 1.9.5
------------
- Goals: a gifts goal can be for one gift. On the Goals tab set the type
  to "gifts", pick the gift (or leave "any gift") and enter how many,
  e.g. 50 Roses. Only that gift fills the bar, and the goal bar overlay
  shows the gift's picture and name.

NEW IN 1.9.4
------------
- GT big key game: guesses are now 1-22, the places Ganon's Tower's big
  key can actually be: Bob's Torch and every chest except the Big Chest
  and the four behind the big key door. Chest numbers count only those.

NEW IN 1.9.3
------------
- Comments add time to the subathon clock too: set seconds per comment on
  the control panel's Subathon tab, plus an optional wait before the same
  viewer's next comment counts again (stops one viewer spamming the clock).
- Test chats on the control panel add time when "Also run the game
  effect" is ticked, like the other test buttons.

NEW IN 1.9.2
------------
- Time on the subathon clock from the crowd, not just coins: set seconds
  for each like (as small as 0.01), follow, share, new Super Fan and new
  community member on the control panel's Subathon tab.
- Effects for new Super Fans and new community members (Gifts & effects
  tab), with their own alerts (Alerts tab) and test buttons.
- TikTok events Crowd Control+ doesn't use yet are listed once each in
  the black window ("TikTok event not used: ..."), so a renamed event can
  be spotted and added.

NEW IN 1.9.1
------------
- Fixed: the subathon clock on the control panel ran about twice as fast
  as the real clock (one second, then a jump of two or three), so after a
  while it showed far less time than the game and the stream overlay.
  The real clock, the clock on the game and the /timer overlay were right
  all along; only the control panel's display was off.
- New effects for the item sound packs: sound_pack_next and
  sound_pack_random switch which pack plays on item pickups.
- Works with Zelda 1 (Z1R) in Rando Hub too: same bridge, same
  mapping.json. Effects that only exist in ALTTP are skipped while
  Zelda 1 is playing.

NEW IN 1.9.0
------------
- GT big key guessing game (Live games tab): chat guesses which Ganon's
  Tower chest has the big key (!gt 1-26). The game counts the GT chests
  you open and picks the winners when the key turns up. New "GT big key"
  overlay, and a "BIG KEY FOUND!" alert.

NEW IN 1.8.0
------------
- Checks and bosses on the subathon clock (Subathon tab): e.g. take
  1 minute off per check and 5 minutes off per boss beaten, or add time
  instead. Counts from when Crowd Control+ first sees the game; boss
  detours don't count. The clock overlay shows each change in red with
  the reason. Optional "BOSS DEFEATED!" alert.
- Boss detours read the game's "boss beaten" flag correctly now, so
  "random boss" really skips bosses you've beaten, and a detour to a
  beaten boss brings the boss back for the fight.

NEW IN 1.6.0
------------
- New effects: Random enemy (one that fits the area), Small magic
  refill, Warp to a random dungeon, Flute warp (random flute spot),
  Random warp (either).
- Several like triggers at once, e.g. +1 heart every 300 likes, small
  magic every 500, full heal every 2000 (Gifts & effects tab).
- Boss detour "random boss" only picks bosses you haven't beaten yet.

NEW IN 1.5.0
------------
- LOCAL SIGNER (recommended): no TikFinity needed. Type your TikTok name
  on the Dashboard and click Connect. Crowd Control+ opens your LIVE page
  in its own Chrome / Edge window (log in once, keep it open, it's muted)
  and reads gifts, likes, follows, shares and chat from it. Free, no keys.
- TikFinity stays as a one-click backup if a TikTok update breaks the
  local signer: Dashboard -> TikTok connection -> "TikFinity (backup)".
- Old mapping.json files keep using TikFinity until you switch.

MOVING OVER FROM THE OLD CROWD CONTROL (RETIRED IN 1.4.0)
---------------------------------------------------------
1. Close the old bridge's black window for good.
2. Extract Crowd Control+ to its own folder.
3. Copy your old mapping.json into it (say Yes to replace), so your gift
   setup comes along. timer-state.json can be copied the same way to
   keep your subathon clock.
4. Double-click "Start Crowd Control+.bat".
The game's Crowd effects address stays ws://localhost:21214.
Full guide: INSTRUCTIONS.txt.
