CROWD CONTROL+  (for Rando Hub)
TikTok LIVE crowd control with a control panel and stream overlays
Complete setup guide (no experience needed)
=========================================================================

WHAT THIS IS
------------
You play A Link to the Past Randomizer in Rando Hub while you stream on
TikTok LIVE. When viewers send gifts, like, follow or share, things happen
in your game: extra hearts, lost rupees, inverted controls, slippery ice,
angry cuccos, extra enemies, even a brand-new seed.

Crowd Control+ is Rando Hub's crowd control: the gift bridge, plus:

  CONTROL PANEL   A page in your browser where you set everything up with
                  menus and buttons instead of editing files: which gift
                  does what, test buttons, alerts, goals, chat, the
                  subathon clock, and saved setups ("profiles").
  OVERLAYS        Things your viewers see on stream, made for OBS and
                  TikTok LIVE Studio, in the Rando Hub style:
                    - Gift alerts (with sounds; bigger gifts = bigger alerts)
                    - Goal bars (coins, likes, follows, shares or gifts)
                    - Top gifters leaderboard
                    - Recent events feed
                    - Chat command replies (!rules, !effects, !timer ...)
                    - Chat votes, team battles, the mystery box, the
                      combo meter and predictions
                    - Run stats (deaths, checks, where Link is, music,
                      seed), hall of fame and "welcome back" pop-ups
                    - The scrolling gift list and the subathon clock
  READ CHAT ALOUD Text-to-speech for viewers' chat messages, with filters.

How the pieces connect (all on the PC you stream from):

  TikTok LIVE --> your LIVE page --> Crowd Control+ --> the game
  (viewers)       (a Chrome/Edge    (this folder)  |-> your overlays
                   window it opens)                '-> the control panel

Crowd Control+ opens your own TikTok LIVE page in a separate Chrome or
Edge window and reads the gifts, likes, follows, shares and chat that
TikTok shows there. This is the LOCAL SIGNER, and it's the recommended
way: free, no other apps, no accounts or keys.

If a TikTok update ever breaks it, switch to the backup, TikFinity (a
free app that does the listening instead), with one click on the
control panel. See "THE BACKUP: TIKFINITY" at the end of Part 1.

You set things up once (about 20 minutes). After that, starting it for a
stream takes three clicks.

WHAT YOU NEED
-------------
  - A Windows PC. (Mac and Linux work too.)
  - A TikTok account that can go LIVE.
  - Your own copy of the original Japanese 1.0 "Zelda no Densetsu:
    Kamigami no Triforce" ROM (.sfc). It isn't included and can't be
    shared.
  - Google Chrome or Microsoft Edge installed (the local signer opens
    your LIVE page in it; Edge comes with Windows).
  - OBS or TikTok LIVE Studio, for the overlays.


=========================================================================
PART 1 - ONE-TIME SETUP
=========================================================================

STEP 1. Put this folder somewhere easy
  Right-click the .zip -> Extract All -> choose your Desktop.
  Run things from the extracted folder, never from inside the .zip.

  Used the old Crowd Control (the "Crowd Control" folder in Rando Hub
  zips up to v1.3.7)? It's retired; this replaces it. Close its black
  window for good, and copy your old mapping.json into this folder (say
  Yes to replace) to keep your gift setup.

STEP 2. Install Node.js (it runs Crowd Control+)
  Go to https://nodejs.org, download the "LTS" version, run the installer
  and click Next through everything.

STEP 3. Start Crowd Control+
  Double-click "Start Crowd Control+.bat". A black window opens (keep it
  open) and the CONTROL PANEL opens in your browser:
      http://localhost:21214/studio
  Bookmark it. If it didn't open by itself, type that address in.

STEP 4. Connect to TikTok (the local signer)
  On the control panel's Dashboard, in "TikTok connection":
  - Leave it on "Local signer (recommended)".
  - Type your TikTok name (without @) and click Connect.
  - A new Chrome / Edge window opens on your LIVE page. Log in to
    TikTok in that window (once; it remembers you next time).
  - Keep that window open while you stream. You can minimize it or put
    it behind other windows. Its sound is muted, so it won't echo.
  The dot turns green ("Connected to TikTok LIVE") once you're LIVE.
  Before you go live it says "Waiting for the LIVE"; that's normal.
  Closed the window by mistake? Click "Open my LIVE window".

STEP 5. Connect the game
  - Open Rando Hub: https://hugecrankhank.github.io/Rando-hub/
    (in Chrome or Edge, on the same PC).
  - Randomizer -> Base ROM... -> pick your Japanese 1.0 ROM (once).
  - The game's ... menu -> "Crowd effects" -> tick "TikTok effects on".
    Bridge address: ws://localhost:21214
  - If the browser asks to allow access to devices on your local
    network, click Allow.
  The control panel's top bar now says "Game connected" (green).

STEP 6. Add the overlays to your stream
  In the control panel, open the OVERLAYS tab. Each overlay has an
  address, a Copy button and a size. For each one you want:

  OBS
    Sources -> + -> Browser -> paste the address -> set the width and
    height shown -> OK. Then drag it where you want it.
    For alert sounds: tick "Control audio via OBS" in that source.

  TikTok LIVE Studio
    Add a "Link" source, paste the address, then size and place it.

  Good starting set: Gift alerts (full screen), Goal bar (top), Top
  gifters (a corner).

That's the setup done.

THE BACKUP: TIKFINITY
  Only if the local signer stops working (TikTok sometimes changes its
  website, and a Crowd Control+ update will fix it):
  1. Install TikFinity from https://tikfinity.zerody.one, open it and
     log in with your TikTok account. Its WebSocket / Events API port
     should be 21213 (the default).
  2. Control panel -> Dashboard -> TikTok connection -> choose
     "TikFinity (backup)" -> Connect.
  Switch back to "Local signer" the same way once it's fixed. Your gift
  setup, overlays and everything else stay the same either way.


=========================================================================
PART 2 - EVERY TIME YOU STREAM
=========================================================================

1. Double-click "Start Crowd Control+.bat". The control panel opens,
   and so does your LIVE window (it reconnects by itself).
   (Using the TikFinity backup? Open TikFinity first.)
2. Go LIVE on TikTok.
3. Open (or refresh) Rando Hub. The panel's top bar should show:
     Connected to TikTok LIVE            (green)
     Game connected                      (green)
     N overlays on stream                (green once OBS is open)
4. Optional: Dashboard -> "Reset stream stats" for a fresh top-gifters
   board, and reset goals on the Goals tab.

Keep the black window and the LIVE window open the whole stream.
Closing the black window stops everything. Keep the control panel tab open too if you use read-aloud.


=========================================================================
PART 3 - THE CONTROL PANEL, TAB BY TAB
=========================================================================

DASHBOARD
  "TikTok connection" at the top: local signer (recommended) or the
  TikFinity backup, your TikTok name, Connect, "Open my LIVE window",
  and a green / red dot with what's happening.
  Totals for this stream, the top gifter, and every event as it happens
  (gifts, follows, shares, chat), with what it did in the game.
  "Test without going live": pretend a viewer sent a gift, followed,
  shared, liked or typed in chat. Alerts, goals and overlays react like
  the real thing. Tick "Also run the game effect" to make it happen in
  the game too (and count toward stats, goals and the subathon clock).

GIFTS & EFFECTS
  Every gift and its effect, with the gift's picture. Change an effect
  from the menu, press Test to try it in the game, x to remove a gift,
  or type a new gift name and press Add gift. Gifts that show up on
  stream but aren't set up appear at the bottom with a + button.
  "Test any effect" has a button for every effect the game has (plus the
  mystery box and the boss-detour rescue).
  Also here: big-donation levels (new seeds by coins), likes / follows /
  shares, and how long timed effects last.

  The same tests are in the game: ... menu -> Crowd effects. There you
  also get "Test one boss", and, while connected, "Fake gift" (alert +
  effect) and "Mystery box". Use whichever is handier.
  Press "Save gift setup" when done. It works right away, no restart.

ALERTS
  Turn alerts on or off, the smallest gift that pops up, how long they
  stay, sound and volume, and whether follows and shares get alerts too.
  Sizes: small, big and huge, each starting at a coin value, with its
  own headline. Test buttons show each size on your alert overlay.

LIVE GAMES
  Chat votes, team battle, mystery box, combo meter and predictions.
  See PART 12.

RUN & STREAM
  Run stats from the game, death tax, clip markers, hall of fame and
  welcome back. See PART 13.

GOALS
  Bars that fill up during the stream: coins, likes, follows, shares or
  gifts. Name it, set the target, tick "On stream" to show it on the
  Goal overlay (several can show at once). +100 / -100 and Reset adjust
  it by hand. Example: "CHAOS SEED" at 5,000 coins, then roll a chaos
  seed when it fills.
  A gifts goal can count one gift only: set the type to "gifts", pick
  the gift in the menu next to it and enter how many (e.g. "ROSE RAIN",
  Rose, 50). "any gift" counts every gift. The overlay shows that
  gift's picture and name ("12 / 50 Roses").

OVERLAYS
  Addresses, sizes and live previews of every overlay, plus settings for
  the leaderboard and the event feed.

CHAT & TTS
  Read chat aloud (see PART 6) and chat commands (see PART 7).

SUBATHON
  The subathon clock: set a starting time, Start / Pause, adjust by
  hand, and choose how many coins buy a second. (Same clock as the
  regular Crowd Control; see PART 8.)

PROFILES
  Save your whole setup under a name ("Chill run", "Chaos night") and
  load it in one click. Loading can keep your current goal progress.


=========================================================================
PART 4 - OVERLAY OPTIONS
=========================================================================

Add these to the end of any overlay address:
  ?scale=1.3     bigger (0.8 = smaller)
  ?bg=0          no background box, just the text and pictures
  ?font=plain    normal letters instead of pixel letters
Combine them with &, for example:
  http://localhost:21214/overlay/goal?scale=1.2&bg=0

Extra options:
  Gift alerts    ?pos=bottom   alerts near the bottom instead of the top
  Goal bar       ?id=g1        show only one goal (ids are in studio.json)
  Top gifters    ?size=3       number of rows

WHITE BOX BEHIND AN OVERLAY?
  The overlays are see-through when there's nothing to show. A white box
  means the page was captured the wrong way:
    - OBS: use Sources -> + -> Browser (not Window Capture or Display
      Capture of a Chrome window). Leave "Custom CSS" as OBS fills it in.
    - TikTok LIVE Studio: use a Link source with the address.
    - Opening the address in Chrome shows white; that's normal, Chrome
      paints white behind see-through pages. It's clear in OBS.
  If your app still can't show it clear, add ?screen=green to the end of
  the address and put a Chroma Key filter (green) on that source.
  Or skip the alerts overlay: gift alerts also show on the game itself,
  over the hearts (game's ... menu -> Crowd effects -> "Gift alerts over
  the hearts", on by default), so they're on stream with the game.

The overlays only work while Crowd Control+ is running. If an overlay
says "Waiting for the Crowd Control+ bridge", start it, then right-click
the source in OBS -> Refresh.


=========================================================================
PART 5 - ALERT SOUNDS
=========================================================================

Alerts play a built-in retro chime (a different one per size). To use
your own sounds, put files in the "sounds" folder named:
    small.mp3   big.mp3   huge.mp3   follow.mp3   share.mp3
(.wav and .ogg work too). Only the ones you add are replaced.

In OBS, tick "Control audio via OBS" on the alerts source so the sound
goes into your stream. Volume is on the Alerts tab.


=========================================================================
PART 6 - READING CHAT ALOUD (TEXT-TO-SPEECH)
=========================================================================

1. Chat & TTS tab -> tick "Read chat aloud" -> Save chat settings.
2. In the "Where it plays" box, tick "Speak in this tab".
3. Press "Test voice". Pick a voice and speed you like.

Messages are spoken by the control panel tab with this computer's own
voices, so keep that tab open while you stream, and make sure OBS / LIVE
Studio captures your desktop audio.

Who gets read: "Viewers who gifted" (at least N coins this stream) or
"Everyone". Messages with links, !commands, or any word on your "Never
read" list are skipped, and long messages are cut off.


=========================================================================
PART 7 - CHAT COMMANDS
=========================================================================

When a viewer types a command in chat, the reply pops up on the Chat
commands overlay. Comes with:
    !effects   the gift list (which gift does what)
    !rules     a message you write
    !timer     subathon time left
Add your own on the Chat & TTS tab. Fill-ins that update by themselves:
    {effects}  the gift list      {timer}  subathon time left
    {top}      top 3 gifters      {goal}   the goal that's on stream
    {coins}    coins this stream
"Wait between uses" stops one command being spammed.


=========================================================================
PART 8 - THE SUBATHON CLOCK
=========================================================================

A countdown clock: you choose how long it starts at, and every coin
viewers donate adds time. Set, Start, Pause and Adjust it on the
control panel's Subathon tab (the old page at
http://localhost:21214/timer/control still works too).

On stream: add the "Subathon clock" overlay (Overlays tab). It also
shows at the bottom of the game unless you turn that off in the game's
Crowd effects menu.

"Coins per second" sets the price: 1 = 3,600 coins an hour, 2 = 7,200,
4 = 14,400, 0.5 = 1,800. The clock is saved, so if you close Crowd
Control+ it comes back paused at the same time.

CHECKS AND BOSSES ON THE CLOCK (Subathon tab, "Progress on the clock")
  Turn it on to have your progress change the clock, for example take
  1 minute off for every check and 5 minutes off for every boss beaten
  (or choose "adds time" instead). Click Save.
  - It counts from when Crowd Control+ first sees the game, so loading
    a game you're halfway through doesn't take hours off at once. A new
    seed starts counting again from there.
  - Bosses: the 10 dungeon bosses, Agahnim and Agahnim 2. A boss beaten
    on a boss detour doesn't count (the detour is undone afterwards).
  - Each change shows on the clock overlay (red for time off, with what
    it was for, like "-5m · beat Armos Knights") and in the Recent list.
    Bosses can also pop a "BOSS DEFEATED!" alert.
  - Test 7 checks / Test a boss try it without playing.
  Crowd effects has to be on in the game (that's how the counts arrive).

    Follow ................ +50 rupees
    Share ................. +10 bombs
    (follows and shares count once per viewer every 10 minutes)

About the new seeds:
  All three are off until you tick "Allow seed reroll" in the Crowd
  effects menu. When one is sent, a banner on the game shows who sent it
  and counts down 10 seconds. During the countdown a "Cancel new seed"
  button appears in the Crowd effects menu if you want to keep your game.
  Then the banner shows the new seed being made, and the new game loads
  with its code. The banner can be turned off in the same menu.

  Same settings: whatever the Randomizer bar is set to right now.

  Random preset: picks one preset from the Saved presets menu, and the
  banner and feed say which one (e.g. "Trinity · AVIANART").
    - If you've starred (★) any presets, it only picks from your stars.
      That's the easy way to choose which presets viewers can land on.
    - Without stars it picks from every preset except glitched-logic ones
      (HMG, OWG, No Logic, Anti-Logic), which can need glitches to finish.

  CHAOS: picks alttpr.com, Kara's branch or AVIANART at random, then sets
  every one of that site's menus at random. The banner shows the site and
  the main settings it landed on. It never picks glitched logic, race
  seeds, AVIANART's timer modes, or Kara's permanent one-hit-KO/gloom.
  If a pick can't be generated, or is still being made after 3 minutes
  (big shuffles on Kara's server can take a long time), it picks again,
  up to 3 tries. The last try is allowed to take as long as it needs.

  Heads-up: a random preset or chaos roll leaves the Randomizer bar on
  those settings, so the next "same settings" roll repeats them. Save your
  usual setup as a preset (Save as preset) so you can switch back to it in
  one click.

About Random sprite / Random MSU pack:
  Random MSU picks from the music packs you've starred in the game's
  music menu. If you haven't added any, the game just says so.

The control panel edits mapping.json for you. If you prefer editing it
by hand in Notepad, it works the same as the regular Crowd Control and

  "openPanel": false     don't open the control panel on start

    hurt_2         -2 hearts (never kills)

                   new community member and comment adds (chatCooldown:
                   seconds before the same viewer's next comment counts) (0 or left out = none; likes
                   add up until they make a whole second). Easiest to set
                   on the control panel's Subathon tab. (Part 8)
  "giftCoins": { "Galaxy": 1000 }
                   only needed if the black window doesn't show
                   "= N coins" for a gift: tells the bridge what it's worth
  "durations": { "one_hit": 20, "no_magic": 20, "cucco_storm": 20 }
                   how many seconds timed effects last
  "likes": [ { "every": 300, "effect": "heal_1" },
             { "every": 500, "effect": "magic_small" },
             { "every": 2000, "effect": "heal_full" } ]
                   like triggers, each counting on its own (add or remove
                   them on the Gifts & effects tab)
  "follow": "rupees_plus"     effect for a follow
  "share": "bombs_plus"       effect for a share
  "superfan": "heal_full"     effect for a new Super Fan
  "community": "rupees_plus"  effect for a new community member
  "maxPerGift": 5             cap for gift streaks (20 Roses = 5 hearts)
  "ticker": { "title": "GIFT EFFECTS", "speed": 70, "rows": 2,
              "labels": { "one_hit": "OHKO mode" } }
                   title, speed, rows (1-4: more gifts on screen at
                   once; 72 px of height per row) and nicer effect names
                   for the scrolling gift list. Rows, title and speed are
                   also on the Gifts & effects tab. The list shows the
                   gifts in their order on that tab (drag or use the
                   arrows to change it). The list shows only what the
                   game that's open can do (Zelda 3 or Zelda 1), and
                   changes on its own when a reroll switches games.


=========================================================================
PART 12 - LIVE GAMES (Live games tab)
=========================================================================

Add each one's overlay from the Overlays tab first.

CHAT VOTE
  Write a question and 2-4 choices, pick an effect for each (or none for
  a plain poll), press Start vote. Chat types 1, 2, 3 or 4. When time's
  up the winner's effect runs. Quick buttons: "Random curses", "Curse or
  blessing", "Which dungeon next?". Ties are settled by chance.

TEAM BATTLE
  Light World vs Dark World (rename them). Viewers type !light or !dark
  to join. Their gifts fill their team's bar; gifters who didn't join
  help the team that's behind. First to the coin target, or ahead when
  the time limit runs out, wins, and that team's effect runs (by
  default: a full heal for Light, a CHAOS seed for Dark).

MYSTERY BOX
  Set "Mystery box" as any gift's effect (Gifts & effects tab), as a
  big-donation level, or as the combo bonus. A slot machine spins on
  stream and lands on a random effect from the ones you tick.

COMBO METER
  Gifts that arrive within a few seconds of each other build a combo.
  Every 10 in a row (you choose) fires a bonus effect.

BOSS DETOUR
  Set a gift to "Boss detour: Ganon", "Boss detour: Agahnim" or "Boss
  detour: random boss" (Gifts & effects tab). The game saves first, drops
  Link into that fight, and when it ends (time's up, Link falls, or he
  wins) it loads the save, so the run carries on exactly where it was:
  same room, same hearts, same items. A gold BOSS DETOUR alert shows on
  stream at the start and end.
    - How long: Gifts & effects -> Timed effects -> boss_detour (60s)
    - Rewards: pick an effect and/or subathon seconds for beating the
      boss and for surviving until time's up
    - "Rescue Link from a boss detour" as a gift's effect ends it early
    - On the game: ⚙ menu -> "End boss detour now" if you need out
    - Testing: "Test one boss" picks a boss and sends Link there. Gifts
      set to the random boss still pick at random.
  Other effects wait until he's back. Early in a seed Ganon is usually
  a survival challenge. Not for races (it's a save state).

PREDICTIONS
  "Will he beat this dungeon without dying?" Chat types !yes or !no
  before it locks. When it's over, press "It happened" or "It didn't";
  the people who called it get a shout-out on stream. Just for fun.

GT BIG KEY (Live games tab)
  "Which Ganon's Tower chest has the big key?" Press Start guessing;
  chat types !gt 1 to !gt 22 (one guess each; a new one replaces the
  old). Guesses close when you open the first GT chest (or press Close
  guesses). The game counts the GT chests you open; when the big key
  turns up, that chest's number wins: exact guesses, or the closest if
  nobody's exact. Add the "GT big key" overlay to show the guesses and
  the winners. Needs Crowd effects on in the game. Counted: the 22
  places the big key can be (Bob's Torch and every chest except the Big
  Chest and the four behind the big key door). Not for seeds with shuffled big keys (keysanity).
  If the game couldn't count it (the game was loaded with the key
  already found), type the chest number and press Set.

DIGGING GAME (Live games tab)
  "Which dig gives the prize?" The Digging Game (Dark World, the shovel
  guy south of the Village of Outcasts) gives its prize on one dig, set
  by the randomizer for each seed. Press Start guessing; chat types
  !dig 1 to !dig 30 (one guess each). Guesses close at the first dig
  (or press Close guesses). When the prize is picked up, the game says
  which dig it came on: exact guesses win, or the closest. Add the
  "Digging Game" overlay to show the guesses, the digs so far and the
  winners. Needs Crowd effects on in the game. If the game couldn't
  tell (the prize was already collected when the game was loaded),
  type the dig number and press Set.

Votes and predictions only count chat messages that are exactly the
number or word (1, !vote 2, !yes ...), so normal chat isn't affected.


=========================================================================
PART 13 - RUN STATS, DEATH TAX, CLIPS, HALL OF FAME (Run & stream tab)
=========================================================================

RUN STATS
  While the game's Crowd effects is on, Rando Hub sends deaths, checks,
  where Link is, the MSU-1 pack and the seed. Add the "Run stats"
  overlay (one row, or ?layout=column for a box).

DEATH TAX
  Every death can add time to the subathon clock (default 5 minutes)
  and/or move a goal, with a "DEATH TAX" alert.

CLIP MARKERS
  Big moments are time-stamped automatically: big gifts, seed rolls,
  deaths, vote and battle winners, combo bonuses, predictions. Viewers
  can type !clip, and "Mark now" adds your own. The time shown is
  stream time since the last "Reset stream stats" (Dashboard), so reset
  at the start of each stream and the times match your recording.
  "Download list" saves them as a text file.

SEED HISTORY (Live games tab)
  Every seed played while the bridge runs, kept across streams in
  seeds.json (this folder): when, the seed and its code, which game,
  who rolled it and how (Generate & Play, the dice Reroll button, a
  gift's new seed / random preset / CHAOS seed, or a roll handed over
  from the other game) and a link to play it again. Download (CSV)
  opens in Excel or Google Sheets. The hub keeps its own list in the
  browser too: Settings menu > Seed history.

HALL OF FAME
  All-time top gifters across every stream (hall-of-fame.json). Reset
  stream stats doesn't clear it; it has its own reset button.

WELCOME BACK
  When a regular (seen in 3+ streams; you choose) shows up for the
  first time in a stream, a small "Welcome back" pop-up says hi. A new
  stream starts when you press Reset stream stats.

MUSIC
  Whenever the MSU-1 pack changes (your music menu, the dice button, or
  a gift), Rando Hub itself shows "NOW PLAYING <pack>" on the game for 3
  seconds. It's part of the game picture, so it's on stream whenever the
  game is, with or without Crowd Control+.


=========================================================================
TROUBLESHOOTING
=========================================================================

Double-clicking "Start Crowd Control+.bat" says "Node.js is not installed"
  Install it from https://nodejs.org (Part 1, Step 2), then try again.

Buttons or the timer do nothing for minutes, then everything fires at once
  Too many Crowd Control+ pages open in the same browser (browsers allow
  about 6 connections to one address). Update to 1.3.4 or newer, keep the
  control panel open in ONE tab, and add overlays to OBS / TikTok Studio
  rather than opening them as browser tabs. The panel shows a red bar if
  it's open in more than one tab.

The black window shows an error about mapping.json when it starts
  mapping.json has a typo (a missing quote or comma). Open it in
  Notepad and compare with the examples in Part 11, or load a
  profile from the control panel.

The dot stays red: "Waiting for the LIVE"
  Normal before you go live. Once you're LIVE: look at the LIVE window.
  If TikTok asks you to log in or to verify ("drag the slider"), do it
  there. If the window shows a different account's page, check your
  TikTok name on the Dashboard and click Connect.

"No Chrome or Edge found"
  Install Google Chrome (or Microsoft Edge), then click Connect. If it's
  installed somewhere unusual, put its full path in mapping.json as
  "browserPath".

Gifts stopped coming through with the local signer, but you're live
  First click "Open my LIVE window" (or reload that window). Still
  nothing? TikTok may have changed its site: switch the Dashboard's
  TikTok connection to "TikFinity (backup)" (Part 1, "THE BACKUP") and
  keep streaming. Check the Releases page for a Crowd Control+ update.

The LIVE window opened with no sound
  On purpose: it's muted so your stream doesn't echo.

"can't reach TikFinity on port 21213" (TikFinity backup only)
  TikFinity isn't open, isn't logged in, or its port isn't 21213.
  The bridge keeps retrying, so just open TikFinity.

"port 21214 is in use (bridge already running?)"
  The bridge is already open in another black window. Use that one,
  or close it and start again.

The game's Crowd effects menu says "waiting for bridge"
  The black window isn't open, or the Bridge address isn't
  ws://localhost:21214. If the browser asked about local network
  access, it has to be allowed.

The game says "TikFinity, not the bridge: use ws://localhost:21214"
  The game's Bridge address says 21213. Change it to 21214.

A gift shows "not mapped" in the black window
  It isn't set up yet, or TikTok spells it differently ("Hand Hearts"
  vs "Hand Heart"). Gifts & effects tab: it's listed at the bottom under
  "Seen on stream but not set up". Press its + button, pick an effect,
  Save gift setup.

Gifts appear in the black window but nothing happens in the game
  Check the game is open and the black window said "game connected".
  Effects wait while you're in a menu, text box or screen transition.

"Extra enemy: No enemies here to copy"
  It only copies enemies already on screen. Find a room with one.

"needs a randomizer ROM"
  Ice physics and Cucco attack use features built into randomizer
  seeds. Generate a seed in the game's Randomizer panel.

Cucco attack does nothing
  It only works outdoors. Indoors its timer pauses, and it picks up
  again when you go back outside.

The scrolling list in OBS is blank or says "Waiting for the bridge"
  Start the bridge first, then right-click the source -> Refresh.

New seed doesn't happen
  Tick "Allow seed reroll" in the game's Crowd effects menu.

A big donation didn't trigger a new seed / didn't add time
  The black window should show "= N coins" next to every gift. If it
  doesn't, TikTok didn't send the coin value: add the gift's value to
  "giftCoins" in mapping.json. Time is only added once the clock has been
  set (Part 8) and while it hasn't run out.

"Can't reach the bridge" on the timer page
  The black window isn't open. Start it, then refresh the page.


=========================================================================

The control panel won't open / says it can't reach the bridge
  The black window isn't open, or something else is using port 21214
  (the regular Crowd Control). Close the other one and start again.
  The address is http://localhost:21214/studio

An overlay is blank in OBS
  Start Crowd Control+ first, then right-click the source -> Refresh.
  Check the address and size match the Overlays tab.

No alert sound on stream
  In OBS, tick "Control audio via OBS" on the alerts browser source, and
  check Alerts tab -> Sound is ticked.

Chat isn't read aloud
  Chat & TTS: "Read chat aloud" ticked and saved, and "Speak in this
  tab" ticked in the panel tab you keep open. Click anywhere on that tab
  once (browsers only allow sound after a click). With "Viewers who
  gifted", only people who gifted this stream are read.

A chat command doesn't pop up
  The Chat commands overlay must be added to your stream, "Commands on"
  ticked, and the command typed exactly (it can't be used again until
  "Wait between uses" has passed).
