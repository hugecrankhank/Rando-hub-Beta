OVERLAYS FOR OBS / TIKTOK LIVE STUDIO

Add each one as a Browser source (OBS) or a Link source (TikTok LIVE Studio) with the address and size shown. They update live. Options go on the end of the address: ?scale=1.3 bigger, ?bg=0 no background box, ?font=plain normal letters instead of pixel letters, ?screen=green solid green behind it for a Chroma Key filter. The page itself is see-through: if you see a white box, it was added as a window or display capture instead of a Browser / Link source.
