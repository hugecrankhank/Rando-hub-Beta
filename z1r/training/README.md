# Z1R Training routes

Routes offered to everyone in **🎯 Training** (the "Built in" group). Record a
route in the app (🎯 Training → ● Record, play it once, then Off), press
**Export**, put the `.z1route.json` file in this folder and list it in
`routes.json`:

```json
[
  { "file": "any-percent.z1route.json", "name": "Any% (from the reference video)" }
]
```

Your own routes stay in your browser (or the Windows app) until you export them;
**Import…** loads a file someone sent you.
